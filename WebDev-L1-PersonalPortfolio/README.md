## 📌 Project Overview
A clean, modern, and fully responsive personal portfolio website built with semantic HTML5 and modern CSS3. This project acts as a digital résumé showcasing personal profile information, a structured "About Me" narrative, a categorized technical skills grid, featured project cards with GitHub repository links, and a direct contact section with social links.

---

## 🎯 Objectives
- Create a personal portfolio website that functions effectively as a digital résumé.
- Implement a hero/profile section with full name, role title, and professional photo/avatar placeholder.
- Provide an About Me section with 2–3 sentences describing background and interests.
- Design a visual grid displaying core technical skills.
- Showcase at least two project cards with project titles, descriptions, and GitHub link placeholders.
- Provide a dedicated Contact section with name, email, and social profiles (LinkedIn and GitHub).
- Implement smooth scroll navigation between sections.
- Maintain consistent branding (color palette and typography hierarchy) across the entire site.
- Ensure 100% responsiveness on desktop, tablet, and mobile devices.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic document structuring (`<header>`, `<nav>`, `<section>`, `<footer>`, headings, anchors, lists)
- **CSS3:** Flexbox, CSS Grid, smooth scrolling, CSS custom variables, media queries
- **JavaScript:** None required (fully implemented using pure HTML5 and CSS3)

---

## ✨ Features Implemented
1. **Profile / Hero Section:**
   - Full Name placeholder: *Alex Morgan*.
   - Professional Role Title: *Frontend Web Developer & UI Designer*.
   - Profile photo/avatar placeholder with gradient styling and centered avatar icon.
   - Quick action buttons to view projects or jump straight to contact details.
2. **About Me Section:**
   - 2–3 well-structured sentences describing technical background, design philosophy, and engineering interests.
   - Quick metadata summary (Location, Primary Focus, Availability status).
3. **Skills Section:**
   - Visual 6-item CSS Grid of technical competencies (HTML5 & Semantics, CSS3 & Responsive Design, JavaScript Fundamentals, Mobile-First Layouts, Version Control & Git, Web Standards & SEO).
4. **Projects Section:**
   - Features 2 detailed project cards:
     - **Project 1:** *Apex Digital Landing Page* (HTML5, CSS3, Responsive Design).
     - **Project 2:** *Interactive Temperature Converter* (HTML5, CSS3, JavaScript).
   - Each card includes descriptive overview tags and a direct GitHub repository link placeholder.
5. **Contact Section:**
   - Dedicated contact card displaying full name, direct email mailto link, and interactive buttons linking to LinkedIn and GitHub.
6. **Smooth Scrolling Navigation:**
   - Sticky navigation header with smooth transition linking directly to `#about`, `#skills`, `#projects`, and `#contact`.
7. **Consistent Branding & Mobile Responsiveness:**
   - Cohesive Sky Blue / Slate / Navy color scheme (`#0284c7`, `#0f172a`, `#f8fafc`).
   - Unified Segoe UI typography hierarchy.
   - Fluid responsiveness adapting gracefully to viewports below 600px.
