# Web Development & Designing — Level 1 Task 1: Landing Page

**OASIS INFOBYTE Internship (OIBSIP)**  
**Project Name:** Apex Digital Landing Page  
**Track:** Web Development & Designing  
**Level:** Level 1  
**Task Number:** Task 1  

---

## 📌 Project Overview
A visually polished, responsive static landing page built strictly with pure HTML5 and CSS3 (no JavaScript required). This project establishes foundational responsive web layout design, strict visual hierarchy, sticky navigation, distinct content sections, and cross-device responsiveness adhering to the official **OASIS INFOBYTE — SIP Task List** requirements.

---

## 🎯 Objectives
- Build a structured, semantic static landing page for a modern web studio brand (*Apex Digital*).
- Implement a sticky navigation bar with active anchor links.
- Create an engaging hero section featuring a headline, subheadline, and call-to-action button.
- Design at least two distinct content sections (Features, About Us, Testimonials).
- Provide a structured footer with placeholder contact and social links.
- Apply a consistent, accessible color palette without element overlap.
- Ensure 100% responsiveness using CSS Flexbox and Grid.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<section>`, `<footer>`, headings, anchors, lists)
- **CSS3:** Flexbox, CSS Grid, sticky positioning, media queries, CSS variables/box-sizing reset
- **JavaScript:** None (strictly adheres to the official specification: *"no JavaScript required"*)

---

## ✨ Features Implemented
1. **Sticky Navigation Bar:**
   - Remains fixed at the top of the viewport on scroll.
   - Contains navigation links (`Features`, `About`, `Testimonials`) plus a highlighted `Get Started` CTA button.
2. **Hero Section:**
   - Prominent H1 headline: *"Scale Your Digital Presence With Precision"*.
   - Subheadline describing the value proposition.
   - High-contrast Call-To-Action (CTA) buttons linking to core sections.
   - Live platform status visual card with metrics.
3. **Distinct Content Sections:**
   - **Section 1 (Features):** 3-column CSS Grid showcasing core capabilities (Performance, Responsive Architecture, Clean Code Standards).
   - **Section 2 (About Us):** Informative 2-column layout highlighting principles, bulleted checklists, and company mission.
   - **Section 3 (Testimonials):** Social proof section displaying quotes, author badges, and roles.
4. **Footer:**
   - Brand overview description.
   - Placeholder social links (LinkedIn, GitHub, Twitter).
   - Quick navigation links.
   - Contact details (email and telephone placeholders) and OASIS INFOBYTE internship attribution.
5. **Responsive Layout:**
   - Mobile-first Flexbox and CSS Grid layout adapting cleanly across desktop, tablet, and mobile screens (<640px).
   - Zero element overlap with `box-sizing: border-box`.

## 🚀 How to Run
No build step, package manager, or server is required.

   - Clone or download the `OIBSIP` repository.
